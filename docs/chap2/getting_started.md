# Getting Started
{: .no_toc }

These pages describe the official CHAP2.0 workflows: CHAP zero-shot prediction
and CHAP fine-tuning on wrist or hip accelerometer data.

CHAP2.0 lives in the `CHAP2/` directory and is kept separate from the
`MSSE-2021/` implementation.
